# 鼠鼠星球

一个给“已经去鼠星的鼠鼠”做纪念档案的小网站原型。

当前版本包含：

- 星球首页
- 鼠鼠纪念卡片
- 搜索与区域筛选
- 详情弹窗
- 新增纪念卡表单
- 浏览器本地保存新增鼠鼠
- 鼠鼠详情页视图
- 鼠鼠星球地图
- 可替换的首页主视觉资产
- 顶部分类导航：首页、星球居民、星球地图
- 独立页面：首页 `index.html`、星球居民 `residents.html`、星球地图 `map.html`

直接打开 `index.html` 就可以从首页开始预览。
