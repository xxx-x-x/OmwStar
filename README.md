# 鼠鼠星球

一个给“已经去鼠星的鼠鼠”做纪念档案的小网站原型。长期愿景是收录各个玩家心爱的鼠鼠，让每一位已经抵达鼠星的小居民都能被温柔记住。

当前阶段的定位是：轻量网站 + MySQL 数据库存储 + Redis 缓存的鼠鼠纪念档案原型。
网站保留本地私密草稿能力，同时支持玩家投稿进入数据库待审核，审核通过后进入公开纪念星河。

## 当前边界

- 默认作为个人纪念档案使用
- 本地新增内容仍保存在当前浏览器，适合作为私密草稿
- 投稿内容会保存到 MySQL，默认进入待审核状态
- 公开展示只读取审核通过的数据库档案
- 暂不做评论、关注、排行等强社区功能
- 社区化前先验证玩家主动分享和内容审核边界

更完整的产品路线见 [`ROADMAP.md`](./ROADMAP.md)。

## 本地运行

数据库模式需要先安装依赖、配置环境变量、初始化 MySQL，再启动网站服务。

```bash
npm install
copy .env.example .env
npm run db:init
npm run dev
```

启动后访问：

```text
http://127.0.0.1:4173/
```

`.env` 里需要配置：

```text
DB_HOST=43.143.131.87
DB_PORT=3306
DB_USER=xxxzh
DB_PASSWORD=你的数据库密码
DB_NAME=omwstar
REDIS_URL=redis://127.0.0.1:6379
ADMIN_TOKEN=换成一段很长的审核口令
```

`.env` 已加入 `.gitignore`，不要提交真实密码。

如果只想看静态页面，也可以直接打开 `index.html`。这种模式下会显示示例数据和浏览器本地保存内容，但不会连接 MySQL 或 Redis。

页面入口：

- 首页：`index.html`
- 星球居民：`residents.html`
- 鼠鼠纪念页：`resident.html?id=1`
- 星球地图：`map.html`
- 纪念星河：`planet-wall.html`
- 投稿原型：`submit.html`

## 下一步重点

优先把项目打磨成一个完整的个人档案工具：

- 统一初始数据来源，避免重复维护
- 继续优化更完整的纪念字段
- 强化本地编辑、删除和清空确认体验
- 支持导入和导出纪念档案 JSON
- 增加本地保存、导入导出、删除等操作提示
- 为未来公开分享预留 `visibility`、`createdAt`、`updatedAt` 等字段
- 继续完善投稿原型中的公开确认、撤回和待审核状态

## 未来可能方向

- 生成单张纪念卡图片
- 复制分享文案
- 打印或保存详情页
- 用户主动选择公开的纪念页
- 玩家投稿后的待审核纪念档案
- 继续完善“纪念星河 / 星球墙”的公开展示概念

## 暂不计划

- 默认公开用户内容
- 评论区
- 关注关系
- 排行榜或热度榜
- 未审核公开投稿
- 过早引入账号系统
