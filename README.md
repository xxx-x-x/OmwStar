# 鼠鼠星球

一个给“已经去鼠星的鼠鼠”做纪念档案的小网站原型。长期愿景是收录各个玩家心爱的鼠鼠，让每一位已经抵达鼠星的小居民都能被温柔记住。

当前阶段的定位是：私密、轻量、以本地保存为主的鼠鼠纪念档案工具。
未来会保留向玩家投稿、公开分享和克制社区空间发展的可能，但不会在早期引入账号、评论区、排行榜或默认公开内容。

## 当前边界

- 默认作为个人纪念档案使用
- 新增内容保存在当前浏览器本地
- 暂不上传用户内容
- 暂不提供公开投稿
- 暂不做评论、关注、排行等强社区功能
- 社区化前先验证玩家主动分享和内容审核边界

更完整的产品路线见 [`ROADMAP.md`](./ROADMAP.md)。

## 本地预览

直接打开 `index.html` 就可以从首页开始预览。

页面入口：

- 首页：`index.html`
- 星球居民：`residents.html`
- 星球地图：`map.html`
- 纪念星河：`planet-wall.html`
- 投稿原型：`submit.html`

当前版本包含：

- 星球首页
- 鼠鼠纪念卡片
- 搜索与区域筛选
- 完整本地纪念卡表单
- 编辑本地新增纪念卡
- 删除单张本地新增纪念卡
- 浏览器本地保存新增鼠鼠
- 鼠鼠详情页视图
- 鼠鼠星球地图
- 纪念星河静态概念页
- 本地点灯轻互动原型
- 玩家投稿流程静态原型
- 投稿草稿待审核预览
- 可替换的首页主视觉资产
- 顶部分类导航：首页、星球居民、星球地图、纪念星河、投稿原型
- 独立页面：首页 `index.html`、星球居民 `residents.html`、星球地图 `map.html`、纪念星河 `planet-wall.html`、投稿原型 `submit.html`

## 下一步重点

优先把项目打磨成一个完整的个人档案工具：

- 统一初始数据来源，避免重复维护
- 继续优化更完整的纪念字段
- 强化本地编辑、删除和清空确认体验
- 支持导入和导出纪念档案 JSON
- 增加本地保存、导入导出、删除等操作提示
- 为未来公开分享预留 `visibility`、`createdAt`、`updatedAt` 等字段
- 继续完善投稿原型中的公开确认、撤回和待审核状态

## 未来可能方向

- 生成单张纪念卡图片
- 复制分享文案
- 打印或保存详情页
- 用户主动选择公开的纪念页
- 玩家投稿后的待审核纪念档案
- 继续完善“纪念星河 / 星球墙”的公开展示概念

## 暂不计划

- 默认公开用户内容
- 评论区
- 关注关系
- 排行榜或热度榜
- 未审核公开投稿
- 过早引入账号系统
